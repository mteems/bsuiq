Skill rankings

Every skill uses the same bell-curve scale: 50 = D-I average, and every 13.5 points is one standard deviation, so the top end spreads out. Tiers: Elite 80+ (about the top 1%), Plus 70–80 (top 7%), Solid 60–70 (top 23%), Average 40–60, Below 30–40, Poor under 30. Stat colors show where each number ranks among D-I players with 200+ minutes. Orange = good · blue = poor. Click any column header to sort. Hover dotted names for definitions.
Scores and stats come from the RStudio skill model and the 10-season play-by-play archive. Player names link to Bronco IQ player pages when that player is in the current data set.
